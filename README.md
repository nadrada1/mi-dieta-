# Mi Dieta V3.2

## Perfiles
- Nacho: 1.100 kcal · pérdida de grasa · 100 g proteína.
- Lucía: 1.300 kcal · mantenimiento · 80 g proteína.
- Javi: 2.150 kcal · ganancia muscular · 100 g proteína.

## Nuevo en V3.2
El modo de Javi en “¿Qué puedo comer?” ahora analiza simultáneamente:
- kcal consumidas y kcal que faltan;
- proteína consumida y proteína que falta;
- contenido proteico de cada receta;
- ajuste de la receta a las kcal restantes.

Las opciones se ordenan para priorizar el mejor ajuste para ganancia muscular y se muestra cómo quedarían kcal y proteína después de añadir cada receta.

Los datos anteriores de Nacho, Lucía y Javi son compatibles y permanecen en localStorage.
